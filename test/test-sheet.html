CNC Studio — 10 test designs

Draw each one by hand in the app. Numbers are in inches; type them rather than dragging where you can. "Check" is what to look at once it's drawn. Export TAP and PDF on every one.

1 · Plate with holes — fill, R labels, kerf, centre marks

  1. Rectangle R, click a corner, type 20 Tab 12 Enter. Set All corners R = 0.5.
  2. Four circles: C, click, type R 0.375. Set each to inside. Use the distance tool (select plate, then hole) to put each hole exactly 2 in from the corners.
  3. Ø6 window centred (R 3, inside). Snap to the plate's centre — it must offer the part centre.
  4. Slot: rect 8 x 1.25, R 0.625, inside.
  • Holes show the bed through them, not a second blue layer.
  • Circle labels read R only. Click the plate's width label on the bed and retype it to 21, then back.
  • Turn on Kerf: orange band = tool width. Toolpaths dashed, centre crosses on every hole.
  • TAP: 2 passes on 3/16 with the 3/8 tool; holes cut CW (G2), plate CCW (G3).

2 · Corners — per-corner radii, fillet, chamfer, point numbers

  1. Rect 10 x 6; set the four Corner R boxes BL 0, BR 0.5, TR 1.5, TL 1.
  2. Rect 8 x 6, click a side (converts to polygon), then Fillet button → all corners 1, then edit P2 and P4 in the points table to 0.25 and 0.5.
  3. Rect 8 x 7 → Chamfer 0.75 on all corners.
  4. Polygon P: six points 3.5 in from a centre (or Dims… with six sides of 3.5 at 60° turns), fillet 0.4.
  • Point numbers P1… on the canvas match the rows in the table.
  • Chamfer becomes two points per corner; fillet stays one point with an R.
  • Size labels: green W x H under each part.

3 · Bowed edges — grips, bulge readout, side editor

  1. Rect 12 x 8. Select it, drag the round grip on the bottom edge down — watch the bulge number at the cursor — release, then type 1.5 in the bulge column. Top edge: type −1.0. Fillet the two straight corners 0.75.
  2. Lens: polyline L two points 10 apart, Join/close, then bulge both edges 2.5.
  3. Tab: 6 x 7 rect, bow the right side in 1.2.
  • Click one side → orange, panel shows Length / Angle / Bulge sliders. Drag each slider; undo is one step per drag.
  • Arc R column shows the equivalent radius; changing one updates the other.
  • Kerf follows the bowed edge; TAP has G2/G3 there, not tiny lines.

4 · Booleans — union, notch, hole, lens

  1. Two rects overlapping by 4 → select both (first stays) → Union.
  2. 12 x 8 rect + Ø5 circle centred on its right edge → Subtract.
  3. 10 x 8 rect + Ø4 fully inside → Subtract: it must keep the circle as a hole, not delete it.
  4. Two Ø8 circles 5 apart → Intersect (in the Trim/boolean menu).
  5. Extra: two 5 x 5 squares butted edge to edge → Union should still give one 10 x 5.
  • Notch and lens keep true arcs (click an edge: it's an arc, not many lines).
  • Areas look right; nothing refused except when shapes really don't touch.

5 · Offset, hole grid, bolt circle, distance tool

  1. 16 x 10 plate → Offset inward 0.5, keep original, new part cut on.
  2. One Ø0.375 hole at (4.5, 6.5) from the plate corner → Array 4 columns x 3 rows, 3.6 x 2.5 spacing.
  3. Flange R5, bore R1.25 inside; one Ø0.5 hole → Array bolt circle, 8, dia 7, centre on the flange (snap centre).
  4. Select flange then plate → Distance: gap between edges = 2.
  • Grid holes all show bed through; centre crosses on each.
  • Distance dialog shows the equivalent centre-to-centre live before Apply.

6 · Text — single-line engraving and outline cutting

  1. Tag rect 30 x 4.5, R0.5. Text button: PART 12-A 3/16 ACRYLIC, built-in single-line, cap 1.25, engrave 'on'. Move it onto the tag (group moves as one).
  2. Text again: Load .ttf… (yours), type Ab7&, cap 5, cut outside.
  3. Type a character the font lacks (e.g. ☃) — expect a toast naming it, not a silent drop.
  4. Select the block → Edit text… → change the wording; it replaces, not duplicates.
  • Single-line letters are open paths; the tool follows the centreline (toolpath sits on the stroke).
  • Outline text: inside of A and b are inside cuts and show bed through.

7 · Traced template — offsets, arc fit, dimensions

  1. Press T. Step 1, baseline along X, close square, fit arcs, tol 0.01. Paste these 31 offsets (one per line):
    9.000 9.329 9.629 9.901 10.146 10.363 10.554 10.719 10.858 10.971 11.059 11.121 11.159 11.171 11.159 11.121 11.059 10.971 10.858 10.719 10.554 10.363 9.726 9.061 8.369 7.649 6.900 6.121 5.312 4.472 3.599
  2. D: dimension the baseline (0,0)→(30,0), the left height, and the mid height at x=15.
  3. Measure M corner to corner — should read 30 exactly and lock square.
  • Curve passes through every station; edges are arcs where they fit (click one).
  • Dimensions print in the PDF but are absent from the TAP.
  • Click the width label → retype 30 → refused (it has arcs) with a pointer to Scale.

8 · Curves — ellipse, splines, 3-point arc, circle

  1. Ellipse E: click centre, type rX 5 Tab rY 3 Enter.
  2. Spline: six points, click the first again to close. Then an open five-point wave.
  3. Arc A: start, end 8 apart, then a point 2.5 above the middle — the preview must match what lands.
  4. Circle: click, type R 3.5, then click its R label on the bed and retype 3.
  • Centre crosses on ellipse and circle; snapping offers centre, quadrants and the circumference while drawing a line from the circle centre outward.
  • The circle stays a circle after lines cross it (no rim grips, R label stays).

9 · Segmentation — split, delete a side, merge, trim, box-select

  1. Square 10 x 10, line across it 3 up from the bottom → square has 6 sides, line 3 pieces. Click one side → Delete. Box-drag from a corner to the middle → two sides orange → Delete.
  2. Square, K delete the bottom → C. Line from its corner to a point partway along the top. Select both → J: toast says closed, one part, 5 sides; click side 5 → Delete.
  3. Two lines crossing → 4 pieces, each selectable.
  4. Vertical line, horizontal line stopping 0.05 short of it → K click the horizontal's far piece: it heals onto the vertical first, then trims.
  • Hover shows the faint orange line before clicking; double-click gets the whole part back.

10 · Full job — nest, off-bed, groups, tools, save/open, TAP, PDF

  1. 7 rects 6.5 x 7 R0.25 on tool 1 (3/8); 3 circles R2 on tool 2; L-bracket 9 x 9 x 3 on tool 3. Nest.
  2. Put a Ø1 hole in one panel, select panel + hole, Ctrl+G; drag the panel — the hole comes with it.
  3. Move one rect to x = 54 → it turns red and Output warns "outside the bed".
  4. Save project, New, Open it back: same parts, same tools, same machine.
  5. Settings → preset EnRoute current → Apply. Export TAP: first line Creation Date, header ends M5, tool block has S, each entry is a 1 in ramp, safe Z = thickness + 0.1, three tool changes T01/T02/T03.
  6. Export PDF: fit to page with sizes + toolpaths; then Tabloid at 1:2. Title block states the scale.
  • Activity log lists every step: nest, group, save, open, both exports, with filenames and line counts.
